# Optica Frontend

Bem-vindo ao frontend do sistema de gestão da Óptica.  
Este projeto é responsável pela interface do usuário, permitindo gerir pacientes, consultas, vendas, produtos e faturas de forma intuitiva e eficiente.

---

## Funcionalidades

- Dashboard com estatísticas de vendas, pacientes, consultas e faturas.  
- Gestão de pacientes: adicionar, editar e excluir.  
- Gestão de consultas: agendamento, edição e pesquisa por paciente/NIF.  
- Gestão de vendas: criar vendas, adicionar produtos, gerar faturas.  
- Controle de estoque: visualização de produtos com estoque baixo.  
- Interface responsiva, funcional em desktop e mobile.

---

## Tecnologias Utilizadas

- Framework: React (Next.js ou Create React App, conforme projeto)  
- Estilização: Tailwind CSS / Bootstrap  
- Componentes de UI: lucide-react, shadcn/ui  
- Chamadas à API: Axios / fetch  
- Controle de estado: React Context / Redux (se aplicável)
